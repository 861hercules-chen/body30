# 身体三十天

一个单文件的 30 天打卡页：2026年10月21日 — 11月19日，每天一勾，别连着断两天。

- 不需要登录任何账号，不连任何服务器，也不加载外部资源，离线也能用。
- 记录保存在打开它的那个浏览器里（localStorage）。换手机、换浏览器或清除浏览器数据，记录就没了。

## 放到手机上用

最省事的办法是把 `index.html` 放到一个免费的静态网页托管上，得到一个网址，然后在手机浏览器打开，再"添加到主屏幕"。

**GitHub Pages**
1. 在 GitHub 新建一个公开仓库，上传 `index.html`。
2. 仓库 Settings → Pages → Source 选 `main` 分支、根目录，保存。
3. 过一两分钟，网址是 `https://<你的用户名>.github.io/<仓库名>/`。

其他任何能托管静态网页的地方也都行，只要上传这一个文件。

## 改日期

打开 `index.html`，找到这一行，把开始日期改掉即可：

```js
const START = "2026-10-21", N = 30;
```

页面顶部的日期文字在 `id="range"` 那一行，顺手一起改。
